# Serverless Express

## MCP AI Rules Server

This repo's `.mcp.json` registers the `40seas-ai-rules` MCP server (hosted at `mcp.reevol.com`) so AI assistants can read coding rules directly from the platform service. Before doing any work, use the MCP server to fetch rules relevant to this repository.

For setup, see `40Seas/common`: `services/mcp-ai-rules/docs/CONSUMER-SETUP.md`.
